# ⛪ Assembleia de Deus Manancial Serra Azul

[![Deploy status](https://img.shields.io/badge/Deploy-Netlify-00C7B7?style=flat-square&logo=netlify&logoColor=white)](https://assembleiadedeusmanancialserraazul.netlify.app/)
[![License](https://img.shields.io/badge/License-MIT-blue.style=flat-square)](LICENSE)

Website institucional da **Igreja Assembleia de Deus Manancial - Serra Azul**. O projeto tem como objetivo divulgar a programação dos cultos, eventos, horários de reuniões, localização e informações institucionais para membros e visitantes da comunidade.

🔗 **Acesse o site:** [assembleiadedeusmanancialserraazul.netlify.app](https://assembleiadedeusmanancialserraazul.netlify.app/)

---

## 📌 Funcionalidades

- **Início (Home):** Apresentação da igreja e mensagem de boas-vindas.
- **Programação & Cultos:** Informações detalhadas sobre os dias e horários das celebrações.
- **Departamentos / Ministérios:** Apresentação das áreas de atuação da igreja (Jovens, Crianças, Mulheres, etc.).
- **Localização:** Endereço e mapa/instruções para que visitantes encontrem a igreja facilmente.
- **Contato:** Canais de comunicação (redes sociais, WhatsApp ou formulário de contato).
- **Design Responsivo:** Interface adaptada para navegação em computadores, tablets e smartphones.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout e responsividade.
- **JavaScript (ES6+):** Interatividade e dinamismo das páginas.
- **Netlify:** Hospedagem e deploy contínuo do site.
